# BlueCrystal iOS

给 mizzzee_0032 用的 iOS 控制 App（SwiftUI + CoreBluetooth）。

厂家已确认本设备只有伸缩和震动，没有吸力功能。协议仍保留四个通道字节，但索引 2 / 3 恒为 0。

## 功能

- **手感**（手动控制）：照官方 App 的三个 tab
  - 技能：官方五个预设（如影随形 / 疾风旋舞 / 幻影随行 / 水光环绕 / 神龙摆尾）
  - 变频：伸缩 / 震动 0~9（0x06 帧）
  - 手动：伸缩 / 震动 0~99（0x08 帧）
  - 未连接时由邀请卡片 + 大号「连接设备」键说明连接状态；设备卡片只在连接成功或有错误 / 安全提示 / 断开中时出现。连上后才出现心、模式和滑杆
  - 我的收藏（滑杆下面一块）：一排收藏卡片点一下就回来，行尾「收藏此刻」加号卡片，「整理」就地重命名 / 删除（最多 8 组）。
    未连接时也可查看、重命名和删除，召回仍锁住；缓推期间不能「收藏此刻」，避免存下半途强度。
    召回时按该模式范围夹紧，升高的通道按升幅缓缓推上去（小幅约 0.75 秒，从 0 推到满档约 3 秒，每 0.15 秒一步，重复档位保留等待但不重发）、降低的通道立即到位；
    第一步和手动拖动一样走 `send`（过准入 / 额度），后续步骤走 `sendThrottled`（不开闸），中途任何停止都会作废剩下的步骤。
    旧收藏加载时移除未使用通道的值；如果只存了未使用通道则不再显示或召回。
    正在输出时，别的模式的收藏锁住并说明（切模式要先停止并等确认）；点不了时卡片下面写明原因。
    删除后 6 秒内可撤销（旁白开着时 15 秒；连续删除时每条都记着、最多 3 条，撤销一条后剩下的照旧可撤销；同样的手感已经又收藏过时不再放回、撤销条也不再给它；收藏满着时任何撤销条都不给「撤销」（点了只会碰上已满），改写「已满：删掉一组，就能放回」并给「去整理」，满着时只留最近删的一条、更早的一并收起；点「去整理」后这条改为「等空位」：常驻不自动收走（不要了可点「算了」），整理时显示在列表上方（旁白焦点落到第一行的删除键），删掉一组空出位置后撤销条先给它；放回后还有空位，等它时删的那几组照常可撤销，放回后又满了就一并收起；收藏此刻存下的正好是等的那条，一句话说明不用再放回；它常驻时下面照常写收藏为什么点不了；大字号时撤销条的说明在上、按键在下一行；整理中撤销条不收起，整理完重新计时）；改名时不按字数截断（拼音输入不被打断），完成 / 切走 / 下次启动时才截到 12 个字
  - 一键停止（常驻页面底部；任何连接状态下都能点）
  - 「隐私与设备」默认收起（面容 ID 开关、最后一帧、FFA2、版本）；隐私提示不收起。空闲自动停止的说明只在输出中 / 刚空闲停机时出现
- **一起看**（声音联动）：选本地视频，播放时实时分析音轨响度（MTAudioProcessingTap，只读不改声音），约每 0.3 秒把响度变成强度发官方 0x08 帧（伸缩 / 震动，通道 2 / 3 恒为 0）。
  不再使用时间轴脚本：强度只来自声音。RMS 为主、峰值补瞬态的 dB 电平 → 灵敏度（增益，-12 ~ +18 dB）→ 噪声门（带回差，很小的声音为 0）→ 攻击快 / 释放慢平滑 → 强度上限（默认 60%）→ 钳位 0~99；
  联动开关、灵敏度、上限、输出通道（伸缩+震动 / 仅伸缩 / 仅震动）都持久化，电平和强度有实时条。
  暂停、缓冲、跳转、播完、离开页面、退后台、蓝牙断开都立即归零；视频没有音轨或音频分析不可用时照常播放但不输出。
  没准备好时播放键下面列出还差设备 / 视频，点一下去补；设备需要先处理时选视频的幕布、素材行、准备项点一下都会被拦下说明，不再只是灰着。
  打开文件选择器前会先停下联动，选择器底部也有停止键（有红字 / 锁存 / 停止重试中 / 强制断开提示时连设备卡片一起带上，AI 设置页和解锁页同一规则）；停止重试中 / 需要确认物理关机 / 提供强制断开时不弹选择器。
  都齐了但额度不许输出时，播放键下面直接写原因。
  全屏和内嵌进度条拖动时显示预览位置，松手后精确跳转；跳转及随后缓冲期间设备保持零输出，播放头前进后恢复联动。
  暂停中跳转后再播放也先等落点前进；等待期间真正的外部暂停立即停止。
  全屏播放中 4 秒不碰屏幕自动收起控制条（拖进度条、旁白或切换控制开着时不收）；有错误 / 停止未确认 / 物理关机锁定 / 强制断开提示时，顶部显示可滚动的设备卡片（最多长到控制条上沿，放不下时底边挂向下的小箭头，滚到底就收起），控制条不收起。停止键只有一个，永远在右下角同一个位置，旁白优先访问
- **她**（AI 控制）：明月栞那；页头显示当前服务商 / 模型，可快捷切换；输入栏上方有快捷话（没开始时是邀请的话，运行中换成调快慢的话；一点就发，和打字发送同一条路径，都不是停止词；
  等她回复时暂时点不了但不收起，聊天区不跳；未连接或安全规则不允许输出时隐藏快捷话，空状态文案跟着说明，连上 / 限制解除后就会出现）
  点击聊天区或空白背景可收起键盘，拖动聊天记录也可交互式收起；收起后底部标签栏恢复可用，快捷话和停止键不受影响。
- 触感：滑杆档位（变频每档、手动每 10）、连接成功、连接失败 / 新红字（自动停机等，0.8 秒内只震一次）、她回话、收藏
- 没有 18+ 确认页（自用）；可选面容 ID 解锁（回到前台不自动弹验证，点「解锁」才弹；解锁页底部有停止键）。
  设备可能仍在输出、停止未确认、有红字提示、正在连接 / 断开或正在运行时，解锁页换成设备卡片 + 停止键，系统验证框不出现
  （已弹出的验证框会被收掉）。全屏视频、AI 设置和文件选择器上同样会盖这些遮挡
- 退到后台 / 多任务界面时画面模糊：只在 App 不在前台时出现、不拦点击，回到前台立刻消失（不受上面的安全状态限制）
- 界面只显示伸缩 / 震动；技能预设、收藏缓推、视频和 AI 都只控制这两个通道

## 安全机制（数值照搬 legacy `src/safety/limits.py`）

- AI 页在场超时（120 秒没新消息停止）和单条程序 120 秒上限已按用户要求关闭（`AISafety.presenceTimeoutEnabled = false`）
- 时间上限（单次 20 分钟、滚动 30 分钟 1200 秒额度）已按用户要求关闭（`SafetyLimits.timeLimitsEnabled = false`）；STOP、停止确认、锁存、心跳看门狗、断链 / 退后台停机照旧
- 手动、技能、视频的每一帧都经过同一个准入检查；额度跨 App 重启保留，未知运行时长仍保守耗尽完整窗口额度
- 停止 = 0x08 停止帧 → 100ms → 0x06 停止帧（官方迷姬专用停止 video.js handleSlide 的顺序），两帧都收到写入回执才算停；
  失败整对重发，1→2→4→8→16→30 秒退避一直重试；30 秒仍未确认会锁定输出，需关机后点「已物理关机，解除锁定」
- 断开前必须确认停止；确认不了时可以「强制断开」（会再次警告）
- 界面心跳丢失 5 秒、退后台、App 退出、重新连上时都会发停止帧对

## 协议（参数取自官方 App 醉清风 3.5.1 源码 + 真机实抓）

- Service `FFA0` / Write `FFA1`（Write With Response）/ Notify `FFA2`（真机 GATT）
- 通用帧（官方 `be()`）：`AA <cmd> <len> <payload> <checksum>`，checksum = 前面所有字节和的低 8 位
- 通道顺序：伸缩 0 / 震动 1 / 未使用 2 / 未使用 3；`Protocol.swift` 唯一组帧出口会在计算校验和前强制索引 2 为 0，旧值不能绕过
- 0x06 模式帧（官方 `Tt()`）：`AA 06 05 <4 通道> 00 <cs>`，技能预设 / 变频（0~9）用
- 0x08 帧（官方 `at(arr, t)`）：`AA 08 06 <4 通道 0~99> <t 高> <t 低> <cs>`，手动 tab 和视频联动用，t 恒为 0
- 视频页声音联动发 0x08 帧：强度 = 响度经灵敏度 / 噪声门 / 平滑 / 上限后的 0~99，`at(…, 0)`，约每 0.3 秒一拍、只在变化时发（见 `AudioReactiveShaper`，Round4Checks 覆盖）
- 旧时间轴脚本强度照官方 video.js（迷姬 devType 2）：`status = 十档值 × 10`（百分制直接用），取整，非零 +10，最高 99（`officialScriptLevel` 保留给脚本模型和测试）
- 停止帧对：`AA08060000000000FFB7`（官方 `at([0,0,0,0],255)`）→ 100ms → `AA06050000000000B5`（官方 `Tt([0,0,0,0])`，真机实抓一致）
- FFA2 通知会订阅并原样显示 HEX（含义未知，只记录）
- 默认技能"如影随形" `AA06050406000000BF`：保留伸缩 4 / 震动 6，清除旧官方启动帧的索引 2；其余四个预设同样归零未使用通道

## 出包（GitHub Actions）

push 到 main 后先跑 `Tests/ProtocolChecks`（钉住帧字节、官方换算、安全上限、AI 指令解析和停止词），再编译 unsigned IPA，
在 Actions 页下载 `BlueCrystalIOS-unsigned`。App 里「最后一帧」区块显示版本号和构建提交。
Publish Release 会核对运行结果、构建提交、sha256 和 tag 与版本号是否一致。

## 安装到 iPhone（自签）

unsigned 包不能直接装，需要自签（二选一）：

**AltStore**（推荐，有自动续签）：
1. 电脑装 AltServer，手机装 AltStore
2. 把 IPA 拖进 AltStore 安装

**Sideloadly**（Windows 也行）：
1. 打开 Sideloadly，选 IPA，填 Apple ID
2. 点 Start 安装（免费账号证书 7 天过期，到期重装一次）

## 时间轴脚本格式

视频页已改用声音联动，不再导入脚本。下面的格式和解析代码（`TimelineScript` 等）仅为兼容保留，供测试和可能的收藏数据使用：

```json
{
  "intensityScale": "ten",
  "commands": [
    {"commandType": "Thrust", "startTimeSeconds": 0, "durationSeconds": 5, "intensityLevel": 5},
    {"commandType": "Vibration", "startTimeSeconds": 5, "durationSeconds": 5, "intensityLevel": 7}
  ]
}
```

- `commandType`：Thrust（伸缩）/ Vibration（震动）。旧文件中的 `Suction` / `Rotation` 仍可加载，但与已有别名一样被忽略，不产生输出或曲线；只有被忽略通道的脚本会显示简短提示
- `intensityScale`：`"ten"`（0~10，官方格式）或 `"percent"`（0~100）。请务必写上：
  不写时只有出现 >10 的值才能确定是百分制；所有值都 ≤10 时分不清，会按较弱的百分制处理并提示
- 换算成 0x08 强度：十档 5 → 60、10 → 99；百分制 50 → 60（见上面的官方公式）
- 短于 0.1 秒的命令在连续播放采样区间内也至少发一次；seek 跳过的区间和已暂停后的末尾区间不补发

## AI 指令

- 默认提示词只让模型控制伸缩 / 震动：`[CH 伸缩 震动 0 0]`，两项强度为 0~99。
- 兼容旧四值 `[CH c0 c1 c2 0]`，全部参数先严格校验，再强制 c2 / c3 为 0；不支持省略参数。
- 指令仍须单独占一行，`[HOLD 毫秒]` / `[STOP]` 和所有停止词、授权、强度与时间安全限制不变。

## 注意

- 连设备前先断开官方 App（蓝牙独占）
- 0x08 帧和 0~99 范围来自官方源码，mizzzee_0032 真机还没抓到过 0x08 帧（视频联动和每次停止都会发它）
- 官方会按设备从服务器下发滑杆范围（slideInfo），0032 的这份配置没拿到，用的是官方默认值
- **停止确认的含义（M4）**：App 说「停止已确认」，只表示停止帧对两帧都拿到了 BLE 写入回执（链路层），不代表设备已经执行；
  主停止帧 `at([0,0,0,0],255)`（`AA08060000000000FFB7`）还没有在 mizzzee_0032 真机上抓到或验证过，代码层面无法证明它能让设备停。
  上身之前必须在设备不接触身体、随手能断电的条件下逐项物理验证：① 手动 0x08 拉到较高强度后点「停止」；② 视频联动中暂停 / 停止；
  ③ AI 程序以 `[STOP]` 结束、以及中途的全零步；④ 输出中退到后台；⑤ 看门狗 / 单次上限自动停机。任何一项设备没真的停下就不要上身，
  并把当时「最后一帧」和 FFA2 通知日志留下来分析

- AI 控制安全收紧：
  - 停止词随时本地生效，等回复时也能发；中文安全短语（停/停止/别动了/够了/不要了/疼/受不了/慢点停…）出现在消息任意位置、英文独立单词 stop（不分大小写）都会停；“慢”仍交给模型降档。
  - 用户停止、被动停机（看门狗/上限/输出被拒/退后台）、程序以 [STOP] 或全零自动结束、连接离开“已连接”、离开 AI 页都会作废待执行的回复；执行前在主线程再核对授权代次、连接、安全状态、前台和当前页面，后台期间 BLEManager 也拒绝输出。
  - 指令必须独占一行、不在代码块/引用/句中（代码块按 CommonMark 围栏的字符和长度判断，没闭合算到结尾，围栏样式含糊时有指令就作废）；CH 恰好 4 个非负整数、HOLD 恰好 1 个正整数、STOP 无参数；格式错、行内指令、STOP 后还有指令、超过 40 步时整条回复一步都不执行，正在输出则安全停止。
  - 回复未正常结束（finish_reason≠stop / stop_reason≠end_turn、stop_sequence / status≠completed）只显示文字、不执行，正在输出则停止。
  - 没执行的回复回传显示文字而非指令原文；每次请求带最近 20 条消息。
